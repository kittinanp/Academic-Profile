ใส่รูปเครื่อง 6 ชิ้น ในโฟลเดอร์นี้
========================================

แนะนำชื่อไฟล์ (ต้องตรงกับใน index.html):
1. lens-meter.jpg       - เครื่องวัดระยะเลนแว่น
2. sterilizer.jpg       - เครื่องอบฆ่าเชื้อ
3. medicine-mixer.jpg   - เครื่องผสมยาชนิดของเหลว
4. color-camera.jpg     - กล้องตรวจสอบแถบสี
5. alum-cutter.jpg      - เครื่องตัดสารส้ม
6. alum-polisher.jpg    - เครื่องขัดสารส้ม

ขนาดที่แนะนำ:
- 800 x 480 px (อัตราส่วน 5:3)
- jpg หรือ png ก็ได้
- ขนาดไฟล์ < 300 KB ต่อรูป (เพื่อโหลดเร็ว)

วิธีนำรูปไปแสดง:
1. ใส่รูปทั้ง 6 ชิ้นในโฟลเดอร์นี้ (ตั้งชื่อตามด้านบน)
2. เปิด ../index.html ในโปรแกรม text editor
3. ค้นหาแต่ละ <!-- TODO: replace with <img... --> comment
4. แทนที่บล็อก <svg>...</svg> ด้านล่าง comment ด้วย:
   <img src="img/consulting/lens-meter.jpg" alt="เครื่องวัดระยะเลนแว่น">
5. ทำซ้ำสำหรับแต่ละเครื่อง
6. ใส่คำอธิบายจริงในแต่ละ <p class="muted-desc">
   (แล้วลบ class="muted-desc" ออกเพื่อให้ตัวอักษรเป็นปกติ)

ถ้าใช้ชื่อไฟล์อื่น แก้ใน src ให้ตรงกัน
